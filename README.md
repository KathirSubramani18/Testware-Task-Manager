# Testware Task Manager
This Task manager is a capstone project with several features like add, delete tasks, etc.

## Features
- Add tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Display task counters

## Technology Stack

Frontend: React, Vite, Axios, CSS
Backend: Node.js, Express.js
Database: MySQL
Deployment: Vercel, Render

## Project Structure

client/ - React frontend
server/ - Express backend
